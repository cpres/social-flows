# brand/

Logos and fonts for the title and end card. Everything here except this file
stays on your Mac (it's in `.gitignore`).

- `oufp.png`, `garden-steward.png`: transparent PNGs. Footage Studio's
  *Title & end card* settings pick these by name.
- Optional: drop Playfair Display and Roboto font files (`.ttf`/`.otf`) here,
  or install them, and the cards use them. Without them the cards fall back
  to Georgia and Helvetica.
