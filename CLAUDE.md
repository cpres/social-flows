# social-flows

A local, personal project of Cypress's: Footage Studio (`studio/`) and the
montage engine (`montage/`), run on a Mac. No other users, no deploys.

## Where the work is

- Weave (the `WeaveView` wizard) was demoted in October 2026. Most work now
  goes into the Relay form; put new features there (or on the shoot page,
  which feeds it) rather than into Weave unless asked.

## Git

- Commit straight to `main` and push it. No feature branches or pull
  requests; changes are tried out by pulling main and running
  `./studio/run.sh`.
